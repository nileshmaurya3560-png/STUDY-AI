
# STUDYSPARK AI 📚

### Your Smart AI-Powered Study Assistant

STUDYSPARK AI is a web-based study assistant designed to make learning easier, faster, and more effective. It uses Google's Gemini AI to help students understand topics, create summaries, practice quizzes, and prepare for exams.

## ✨ Features

- **AI Summary:** Generate simple summaries of study topics.
- **Quiz Generator:** Create quizzes with five questions.
- **Flashcards:** Generate flashcards for quick revision.
- **Explain Simply:** Understand difficult topics in simple language.
- **Multiple Languages:** Supports English, Hindi, and Marathi.
- **Difficulty Levels:** Choose Easy, Medium, or Hard.
- **Study History:** View previously generated study content.
- **Quick Notes:** Save personal study notes.
- **Bookmarks:** Save important AI-generated content.
- **Daily Study Goal:** Set and track daily study sessions.
- **Study Statistics:** View your study progress.
- **Dark Mode:** Switch between light and dark themes.
- **Daily Motivation:** Get motivational messages while studying.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` using the Live Server extension.
5. Add your Gemini API key when prompted.
6. Enter a topic and start learning!

## 🔑 Gemini API Setup

1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Create a Gemini API key.
3. Open STUDYSPARK AI in your browser.
4. Enter your API key in the application.

**Important:** Never upload your API key to GitHub. For a publicly deployed version, use a secure backend to protect the key.

## 🎯 Project Objective

The main objective of STUDYSPARK AI is to help students learn smarter by using artificial intelligence. It makes studying more interactive through summaries, quizzes, flashcards, and personalized revision tools.
