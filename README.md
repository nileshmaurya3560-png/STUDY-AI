# STUDYSPARK AI

**Live Demo:** [Click here to visit STUDYSPARK AI](https://study-ai-eight-ashy.vercel.app)

An AI-powered study assistant designed to make learning easier and smarter using Gemini AI.

## Features
- AI Notes Summarizer
- Quiz Generator
- Flashcards
- Explain Simply
- Multiple Language Support
- Study History
- Quick Notes
- Bookmarks
- Daily Study Goal
- Dark Mode

## Technologies Used

- CSS
- JavaScript
- Gemini AI API
- Local Storage
